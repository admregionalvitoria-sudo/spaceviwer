# SpaceViewer display tools

`SpaceviwerStreamDisplayCtl.exe` (virtual display creation, extend/duplicate topology and display modes) is built from `native/spaceviwerstream`. Original source notices are retained in `native/spaceviwerstream/THIRD_PARTY_NOTICES.md` and `third_party`.

The signed virtual display driver package (MttVDD) and its license are in `driver/virtual-display`.

The GameStream host, Sunshine runtime and VB-CABLE package are no longer distributed.
